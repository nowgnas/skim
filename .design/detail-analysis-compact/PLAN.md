# PR 상세 분석 요청 영역 축소

## 요청과 설계

- PR 상세의 긴 분석 설명을 없애고 분석 버튼과 간단한 진행 상태·결과를 표시한다.
- 분석이 허용되지 않았거나 최신 스냅샷이 없는 경우에는 필요한 조치만 짧게 안내한다. 분석 동의는 기존 저장소 설정과 서버 검증을 유지한다.
- 작업 폴링에서 대기·진행·완료·실패 상태를 갱신하고, 결과나 오류를 접지 않고 짧게 표시한다. 다른 PR 분석이 진행 중일 때도 해당 상태를 보여준다.
- 기존 작업 API에 분석용 표시 문구를 추가하고 다른 화면의 요약은 유지한다.

## 검증

- Python 구문 검사, `node --check lib/skim/web_static/jobs.js`, `git diff --check` 통과.
- 자동 테스트와 실제 화면 검증은 실행하지 않았다.
- 독립 리뷰에서 동의 검증 유지와 다른 PR 상태 표시를 확인했다. 분석 전용 폴링·결과 표시의 자동 테스트가 없다는 지적은 미해결이며, 실제 화면에서도 확인하지 않았다.
