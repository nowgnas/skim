# 모델 선택과 화면 배치 개선

> 상태: 완료 · 기준 커밋: `d6a0d42` · 규모: 표준 · 고위험: 아니오

## 1. 요구사항
- 모델을 텍스트 대신 드롭다운에서 선택해 잘못된 모델명 입력을 줄인다.
- 전체 화면의 버튼과 행의 간격·위치를 개선하고 좁은 화면에서도 조작하기 쉽게 한다.
- Claude의 디자인 리뷰를 검토해 필요한 개선을 반영한다.

## 2. 정책 점검
- ✅ 기존 분석 동의, 예산, 모델 우선순위, probe 및 설정 파일의 보안 규칙을 유지한다.
- ⚠️ 모델 선택지는 사용자 Codex의 로컬 모델 목록에서 가져온다. 목록이 없거나 읽을 수 없으면 임의의 모델을 만들어 내지 않고 자동 선택과 현재 설정값을 보존하며 상태를 안내한다.
- ⚠️ 목록은 캐시이므로 실제 사용 권한과 최신 상태를 보장하지 않으며, 기존 probe로 검증한다. 환경 변수의 우선권은 유지한다.
- ⚠️ 이전에 직접 설정된 모델은 선택지에 포함해 설정이 사라지지 않게 한다. 다른 모델은 목록에서만 선택하도록 서버에서도 검사한다.

## 3. 열린 질문
- 없음. 모델 목록 출처와 실패 처리, UX 변경 범위에 대한 승인 필요.

## 4. 코드 맥락
- `lib/skim/web_settings.py`: 모델 설정 폼과 서버 검증, 저장소 및 정책 목록.
- `lib/skim/config.py`: 모델 형식과 환경 변수 우선순위.
- `lib/skim/web.py`, `web_jobs.py`, `web_static/app.css`: 주요 화면과 공통 UI.
- `tests/test_web_settings.py`, `tests/test_web.py`, `tests/test_web_jobs.py`: 설정·페이지 검증.
- `docs/images`: 기존 디자인 참고 이미지. 현재 구현과 다를 수 있음.

## 5. 설계
- 서버 측에서 로컬 Codex 모델 캐시의 표시 가능한 모델만 제한적으로 읽어 드롭다운을 구성하고, 기본 모델 자동 선택을 제공한다. 검색 목록이 없을 때는 상태를 알린다. 인증 파일이나 비밀값은 읽거나 노출하지 않는다.
- 기존 config.json과 환경 변수 설정은 호환하고, 선택지에 없는 모델을 POST하는 요청은 허용하지 않는다. 목록의 유효성, 크기 및 읽기 실패를 처리한다.
- Claude 리뷰와 현재 코드를 대조해 검색창과 버튼 정렬, 중복 구분선, PR 행의 빈 간격과 링크 중복, 작은 터치 영역, 상태·복구 영역을 개선한다. 분석 요청 패널을 변경 목록 앞에 배치한다.
- 작업 완료 시 사용자가 폼을 편집 중이면 자동 새로고침으로 입력이 사라지지 않도록 한다. 같은 작업의 반복 상태 알림도 줄인다.
- 오류 화면은 공통 레이아웃과 안전한 복귀 동작을 사용한다. 호스트 삭제의 별도 확인 절차와 문서 이미지 교체는 이번 간격·위치 요청 범위를 넘어 후속으로 기록한다.
- 디자인 리뷰는 과거 이미지와 현재 코드를 기반으로 했으며 현재 브라우저를 렌더링한 결과가 아니다.
- API·DB 스키마는 변경하지 않는다. 모델 저장 입력의 허용 범위는 UI 선택지로 제한된다.

## 6. 검증 계획
- 모델 목록 정상·없음·손상, 기본 선택, 기존 설정 보존, 허용하지 않은 POST, 환경 변수 우선순위와 안전한 파일 저장을 확인한다.
- 각 페이지의 버튼·행 구성과 작은 화면을 점검한다. 전체 테스트와 독립 리뷰를 수행한다.

## 8. 결과
- Codex 로컬 모델 캐시 기반 선택과 자동 선택을 추가했다. 목록에서 빠진 기존 설정도 보존한다.
- 목록·버튼 정렬과 모바일 폭을 조정하고, 분석 요청을 상세 상단으로 옮겼다. 편집 중 작업 종료 시 입력을 보존한다.
- Claude 디자인 리뷰: 저장소 이미지와 코드 기반으로 검토했다. 호스트 삭제 확인 절차와 문서 이미지 갱신은 후속 과제다.
- 테스트: `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -q`. 독립 리뷰: 🔴 0, 🟠 0, 미해결 0.
- 화면 확인: 데모 fixture에서 생성한 정적 HTML로 다섯 페이지 및 390px 화면을 확인했다. 실제 서버 또는 서비스 연결을 검증한 것은 아니다.
