# 남은 이슈 정리 계획

## 범위
- #63: 닫힘·머지 시각이 확인된 PR만 `retention_days` 이후 스냅샷과 분석 기록을 정리한다. 다른 스냅샷이 참조하는 diff는 보존한다.
- #64, #66, #68: 이미 반영된 캐시·격리·정제 동작의 누락된 회귀 검증을 추가하고 결과에 따라 수정한다.
- 직전 복구 버튼 변경은 별도 PR로 정리한다.

## 데이터 및 동시성
- 닫힘·머지 시각을 저장하는 nullable 필드를 새 마이그레이션으로 추가한다. 시각이 확인되지 않는 기존 닫힌 PR은 추정해서 지우지 않는다.
- 자동 정리는 수집 잠금을 가진 상태에서 분석 잠금을 논블로킹으로 확보한 경우에만 수행하고, 실패하면 다음 주기에 미룬다. 기존 분석은 분석 잠금 후 수집 잠금을 얻으므로 양쪽에서 대기해 교착되지 않도록 한다.
- SQLite 트랜잭션에서 스냅샷과 종속 분석을 삭제한 후 기존 고아 diff 정리로 참조가 없는 캐시만 삭제한다. 실행 중단 뒤에도 다음 주기에 고아 파일을 정리한다.
- 기본 보존 기간 7일은 기존 Config 계약에 따른다. 실제 정리 동작을 설정 및 문서에서 명확히 안내한다. DB 마이그레이션은 기존 방식대로 백업하고 버전을 올리며 구버전은 새 버전 DB 열기를 거부한다.

## 검증 및 제한
- 임시 데이터로 삭제 경계, 미확인 시각, 재오픈, 공유 diff, 실행 중 분석과 충돌, 실패 복구를 검증한다.
- 캐시 무효화와 ETag 304, 기능 목록 변경시 probe 차단, 정제의 허용 값과 비밀값을 회귀 검증한다.
- 새 정제 정책의 실제 모델 릴리스 평가는 별도 사람이 결과를 확인해야 한다. 평가가 통과하기 전에는 릴리스 차단을 해제하지 않는다.

## 복원력 리뷰 반영
- PR 및 snapshot 숫자 ID 재사용 시 기존 분석 작업이 다른 PR에 연결되지 않도록 삭제 트랜잭션에서 대상 작업을 취소하거나 연결을 해제한다.
- 수집 잠금 하에서 비정상 종료로 남은 소유자 확인된 일반 diff 임시 파일을 정리한다.
- 네트워크 조회는 DB 쓰기 트랜잭션 밖에서 제한된 배치로 수행한다. 종료 시각이 없는 기존 닫힌 PR을 별도로 확인하며 조회 실패 시 보존한다.
- 분석 잠금은 비차단으로 확보하며 획득하지 못하면 즉시 보류한다. DB 커밋 후 고아 파일 정리는 다음 실행에서도 복구한다.
