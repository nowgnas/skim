# PR 목적과 중요도 분석 프롬프트

## 요청과 설계

- PR 제목·설명과 제공된 변경을 함께 살펴 목적과 실제 변경의 관계를 파악한다.
- 핵심 업무 로직, 큰 영향이나 복구가 어려운 변경을 high로 평가하고 mid/low 기준도 명시한다. 경로와 단어만으로 판정하지 않고 바뀐 동작과 영향에 근거한다.
- 각 청크는 전체 PR이 아니므로 다른 변경을 보았다고 가정하지 않고 불확실성을 남긴다. 기존 JSON 계약, 민감 정보 처리, 격리, 호출 예산, 독립 규칙 후보와 파일 최고 중요도 집계는 유지한다.
- 프롬프트 버전을 변경해 기존 결과 캐시와 분리한다. 출시 평가는 새 버전의 실제 모델 결과가 필요하며 기존 근거로 대체하지 않는다.
- 사용자가 제안된 프롬프트와 대표 PR 평가를 승인했다.

## 검증 계획

- 프롬프트의 등급 기준·안전 지시, JSON 계약, 버전과 캐시 무효화를 격리 테스트한다.
- 새 프롬프트 평가 경로와 출시 차단을 확인한다. 실제 모델 평가가 불가능하면 이유와 범위를 보고한다.

## 결과

- 프롬프트 버전을 `skim-ko-4`로 변경하고 기존 청크·합성 JSON 계약과 캐시 키 분리를 유지했다.
- 기존 평가 18개와 diff를 보존하고 핵심 주문 처리·배포 전략 변경 평가 후보 1개를 추가했다. 새 manifest의 기대 파일은 사람의 확인이 필요하다.
- 임시 홈과 실제 Codex CLI에서 기존 PR 2 사례를 실행했다. 기본 사례와 제목·설명을 보충한 실험 모두 분석 완료, 평가 기준 미포착 0건, 표시 누락 0건이다. 보충 실험에서 `lib/skim/cli.py`, `lib/skim/config.py`, `lib/skim/db.py`를 high로 판정했다. 모델 식별자는 `unknown`으로 기록되었고 실험 결과는 정식 출시 근거로 저장하지 않았다.
- `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -q`: 387개 통과. `git diff --check`: 통과. `python3 scripts/check_release.py`: 확인자 미기록으로 출시 차단(예상된 종료 1).
- 독립 리뷰를 두 차례 요청했으나 리뷰 모델의 용량 부족으로 실행되지 않았다. 변경 diff와 버전·출시 차단 경로를 직접 검토했으며 독립 리뷰는 미완료다.
- 실제 모델 평가 2회는 동일한 대표 사례 1건에 대한 실험이다. 전체 19개 사례, 신규 사례의 사람 확인 및 평가 결과 검토는 미완료다.
