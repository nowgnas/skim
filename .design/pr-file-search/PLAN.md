# PR 파일 검색 개선

## 목표와 범위
- 파일 검색 영역을 식별하기 쉽게 하고, 포커스 시 현재 PR의 전체 파일 경로를 표시한다.
- 입력 후 250ms 동안 추가 입력이 없으면 파일 경로에 포함된 문자열로 후보를 좁힌다.
- 후보 선택 시 해당 파일을 열고, 기존 검색 버튼과 변경 내용 검색 및 페이지 이동을 유지한다.
- 마우스와 키보드로 후보를 선택하고 Escape와 외부 클릭으로 닫는다. 서버 API와 데이터 모델은 바꾸지 않는다.

## 설계
- PR의 전체 파일 경로로 서버가 후보를 렌더링하고, 브라우저에서 필터한다. 후보 선택 URL은 기존 file 파라미터를 사용하고 검색 및 페이지 조건을 초기화한다.
- 기존 검색 폼의 GET 동작을 유지하며 JavaScript가 없을 때도 검색할 수 있다. 목록은 스크롤을 지원한다.
- 검색 UI와 접근성 상태는 현재 PR 상세의 기존 HTML·CSS·JavaScript 구성에 맞춘다.

## 확인 방법
- Python 및 JavaScript 구문, 변경 공백과 PR CI 결과를 확인한다. 실제 브라우저와 자동 테스트는 별도 실행하지 않는다.
