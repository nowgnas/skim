# 메인 PR 수집 현황 표시

## 요청과 설계

- 메인 상단에 GitHub에서 연결한 저장소의 PR 정보를 가져오는 작업임을 표시한다.
- 수집 시작 대기, 실패 후 재시도 대기, 수집 중, 완료·실패를 구분하고 재시도 및 종료 시각의 의미를 표시한다.
- 접힌 결과 영역을 `수집 결과와 오류 보기` 버튼 형태로 제공하고, 진행 중 재시도 오류도 폴링 시 갱신한다.
- 기존 작업 큐와 수집·분석 정책은 변경하지 않는다. 다른 화면의 일반 작업 요약은 유지한다.

## 검증

- `python3` AST 구문 검사, `node --check lib/skim/web_static/jobs.js`, `git diff --check` 통과.
- 실제 화면과 자동 테스트는 실행하지 않았다.
- 독립 리뷰를 요청했으나 리뷰 모델 용량 부족으로 실행되지 않았다. 직접 수집 스케줄러와 폴링 경로를 확인했다.
