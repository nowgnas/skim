# 메인 PR 검토 화면

## 요구와 결정

- 메인에는 사용자가 연결한 저장소의 열린 PR을 표시한다.
- 분석 결과가 현재 변경에 적용되고 분석이 허용된 PR은 중요도 높음, 보통, 낮음 순으로 표시한다. 같은 중요도에서는 리뷰 요청을 먼저 표시한다. 미분석·오래된 결과는 우선순위 미확인으로 표시한다.
- 상단에 전체 PR, 리뷰 요청, 높은 중요도 PR 수를 보여주고 기존 검색·저장소 선택·탭·페이지 이동을 유지한다.
- PR마다 제목, 저장소, 작성자, 리뷰 요청, 중요도, 변경 의도, 분석 상태와 검토할 파일을 구분한다.
- 2026-11-03 사용자 승인: 1·3·4 동의, 2는 연결한 저장소를 우선순위 순으로 표시.

## 영향

`lib/skim/web.py`의 메인 목록 정렬·표시와 `lib/skim/web_static/app.css`에 한정한다. 수집, 분석 허용, 기존 앱 설치와 DB를 변경하지 않는다.

## 검증

Python 구문을 확인했다. 메인 화면의 동작 및 실제 화면 검증은 아직 수행하지 않았다. 설치·업데이트 테스트는 별도 작업의 기존 검증 범위에 속한다.

## 결과 및 리뷰

- 독립 리뷰에서 분석 완료·일부 분석 상태 표시 누락을 발견해 카드에 추가했다. 변경 의도가 없으면 상세 재분석 링크도 표시한다.
- 기존 리뷰 요청 우선 정렬 테스트의 기대를 중요도 우선 정렬에 맞춰 변경했다. 테스트 실행과 실제 화면 확인은 하지 않아 결과는 미확인이다.
- 설치·업데이트는 별도 계획의 미완료 상태이며 기존 앱 전환이나 재시작을 수행하지 않았다.
