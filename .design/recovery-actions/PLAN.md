# 안내문에서 복구 작업 실행

## 목표와 범위
- PR 분석 결과, 작업 기록, 상태 점검, 모델 설정의 복구 안내에서 기존 작업 큐를 통해 격리 검증 및 초기화·상태 점검을 실행한다.
- 격리 검증은 실제 모델 호출 비용 안내와 명시적 동의를 유지한다. 기존 전용 홈 재설정은 전용 홈 내용과 probe 기록을 삭제하므로 별도 설명 및 명시적 확인을 요구한다.
- 명령 문자열을 셸에서 실행하지 않으며 고정된 작업만 허용한다. gh 인증, 버전 설치와 프로세스 종료 확인은 수동으로 안내한다.
- 작업 진행과 결과는 기존 상태 화면과 작업 큐를 사용한다. 오프라인에서는 작업을 제공하지 않는다.

## 검증 계획
- 사용자 요청에 테스트 실행이 포함되지 않아 테스트는 추가하거나 실행하지 않는다. 구문 및 변경 diff를 확인하고 독립 리뷰를 받는다.

## 결과
- 저장된 PR 분석 오류, 실시간 분석 작업과 작업 기록, 상태 점검, 모델 설정에 고정 복구 작업을 연결했다. 전용 홈 재설정은 삭제 동의와 기존 분석 잠금·실행 표식 확인을 거친다.
- 독립 리뷰에서 PR에 저장된 오류와 일부 격리 실패에 복구 연결이 빠진 점을 반영했으며, 최종 정적 리뷰에서 추가 주요 지적은 없었다.
- Python compileall, JavaScript 구문 검사, git diff --check 통과. 회귀 테스트와 브라우저 동작은 사용자 요청이 없어 실행하지 않았다.
