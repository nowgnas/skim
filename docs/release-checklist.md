# 출시 체크리스트

현재 `skim-ko-3`는 **출시 차단** 상태다. 실제 모델 평가 자료가 없으므로
단위 테스트 통과만으로 출시할 수 없다. `python3 scripts/check_release.py`는
종료 코드 1로 차단한다. 버전을 바꾸어도 차단은 해제되지 않는다.
배포 자동화는 아직 없으며, 향후 배포 작업은 이 명령의 성공을 필수로 확인해야 한다.
로컬 개발·설치와 fake 테스트는 계속 사용할 수 있다.

차단 해제 변경을 검토하기 전에 다음 자료를 저장소에 준비한다.

- 알려진 PR 15개의 고정 diff와 사람이 지정한 high 단위, 인젝션·민감 정보·hunk 없는 변경 사례.
- 평가 입력 식별자와 해시, 프롬프트 버전과 본문 해시, CLI 버전·모델·실행 일시.
- 실제 모델 원본 출력과 skim의 최종 표시 결과(미분석·부분 분석 포함).
- 지정 high가 high 또는 펼쳐진 규칙 후보로 포착되는지의 단위별 대조 결과.
- 지정 high 누락 0건과 미분석 숨김 0건을 확인한 결과 및 검토 기록.

fake 출력·문자열 검사·합성 fixture는 실제 평가를 대신하지 않는다.
자료 검토 후 해당 프롬프트에 한정된 통과 검사를 구현하고, 다른 프롬프트나
근거 누락·실패 결과는 계속 차단하는 회귀 테스트를 함께 추가한다.
